# High-risk map case validation

Source Weaver does not claim broad Hammer, compiler, or runtime compatibility for high-risk maps. This page records the current evidence for risk cases that need explicit qualification before release notes or documentation can make wider claims.

The reproducible validation entry point is:

```bash
scripts/validate-high-risk-map-cases.sh /tmp/sourceweaver-high-risk-map-cases
```

The script generates Source Weaver-authored synthetic VMFs under the output directory, runs portable Source Weaver validation/merge commands, runs the desktop material-preview unit tests for material-aware behavior, writes JSON reports, and writes `SHA256SUMS`. Generated artifacts stay outside the repository.

## Redistribution boundary

The script generates synthetic VMFs and temporary test files. Source Weaver does not commit or redistribute real game maps, Hammer/Hammer++ assets, Source SDK tools, compiler binaries, game runtimes, VPK content, BSPs, MDLs, VTFs, VMTs, materials, sounds, private user assets, or private paths for these cases. Real-tool outputs must remain outside the repository unless redistribution rights are proven and recorded through the third-party policy review process.
