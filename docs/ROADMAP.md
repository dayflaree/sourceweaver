# Roadmap

Feature states: **foundation**, **experimental**, **qualified**, **enabled by default**.

## Phase 0 — Integrity foundation

- Lossless VMF CST and source patching.
- Encoding, newline, duplicate-key, comment, and unknown-block corpus.
- Stable report/patch schemas.
- Compiler discovery and fingerprinting.
- Public CI.

Exit gate: 100% byte-identical round trip for the legal fixture corpus.

## Phase 1 — Semantic analysis

- `srctools` adapter behind the CST.
- Exact FGD/profile resolution.
- entity-I/O, parent, target, asset, instance, and script-risk graphs.
- VMF linter and capacity report.

Exit gate: every supported semantic field maps back to a unique CST span; affected references resolve completely.

## Phase 2 — Geometry kernel

- Convex brush reconstruction.
- robust predicates and tolerances;
- spatial indexes;
- transform propagation;
- duplicate/overlap classifier;
- synthetic geometry corpus.

Exit gate: no invalid generated solid across the golden corpus and compiler tests.

## Phase 3 — Compiler experiment harness

- process isolation and log normalization;
- BSP/PRT/lump metrics;
- baseline/candidate cache;
- GMod Tools++ qualification;
- limit probes.

Exit gate: reproducible baseline results for every supported fingerprint.

## Phase 4 — Deterministic two-map stitcher

- transition graph;
- landmark alignment verification;
- seam selection and exact duplicate removal;
- ID allocation and typed namespacing;
- singleton conflict report.

Exit gate: synthetic transition pairs compile and preserve graph semantics.

## Phase 5 — Lifecycle synthesis

- region controller;
- class lifecycle registry;
- environment handoff;
- forward/backtracking/save/reload scenarios;
- optional GMod runtime component.

Exit gate: full mandatory two-region runtime suite.

## Phase 6 — Conservative optimizations

- nodraw proposals;
- `func_detail` proposals;
- compile/runtime comparison;
- visual regression routes.

Exit gate: zero correctness regressions and reproducible practical gains.

## Phase 7 — Areaportal automation

- empty-space graph;
- graph-cut candidates;
- exact portal fitting;
- door policy;
- two-area compiler proof;
- PVS/runtime objective.

Exit gate: all valid/invalid portal fixtures classified correctly, with no false auto-accepts.

## Phase 8 — Hint search

- structural candidate generator;
- bounded compile search;
- Pareto selection;
- full visibility/runtime validation.

Exit gate: accepted hints improve configured objectives across held-out synthetic maps.

## Phase 9 — Real-world qualification

Use legally supplied original VMFs locally. Store only hashes, aggregate metrics, and non-copyright transformation recipes where permitted.

Exit gate: multiple adjacent-map styles pass without code changes and every unsupported pattern produces a clear blocker.

## Phase 10 — Multi-region planning

- chain capacity planner;
- automatic region partition proposals;
- lifecycle scaling;
- campaign graph reports.

Whole-campaign flattening remains disabled unless every region and aggregate budget passes.
