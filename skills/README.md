# SourceWeaver project skills

These skills are procedural operating manuals for AI coding agents and human contributors. Read the narrowest matching skill before beginning work.

| Skill | Use it for |
|---|---|
| [`sourceweaver-core`](sourceweaver-core/SKILL.md) | Any cross-cutting feature or repository change |
| [`sourceweaver-vmf-integrity`](sourceweaver-vmf-integrity/SKILL.md) | Parsing, serialization, source edits, Hammer++ data |
| [`sourceweaver-geometry`](sourceweaver-geometry/SKILL.md) | Brush reconstruction, transforms, overlap, exact predicates |
| [`sourceweaver-entity-semantics`](sourceweaver-entity-semantics/SKILL.md) | FGD typing, targetnames, I/O, instances, scripts |
| [`sourceweaver-map-stitching`](sourceweaver-map-stitching/SKILL.md) | Transition graph, alignment, seams, namespacing, lifecycle |
| [`sourceweaver-visibility`](sourceweaver-visibility/SKILL.md) | Nodraw, detail, areaportal, hint, occluder automation |
| [`sourceweaver-compiler-validation`](sourceweaver-compiler-validation/SKILL.md) | Compiler discovery, execution, logs, BSP metrics, qualification |
| [`sourceweaver-runtime-validation`](sourceweaver-runtime-validation/SKILL.md) | GMod scenarios, behavior, PVS and performance validation |
| [`sourceweaver-research-maintenance`](sourceweaver-research-maintenance/SKILL.md) | Current web/source research and confidence ledger updates |
| [`sourceweaver-release`](sourceweaver-release/SKILL.md) | Release gates, packaging, reproducibility, GitHub delivery |

## Skill format

Each skill declares:

- when it applies;
- mandatory constraints;
- required inputs;
- ordered procedure;
- acceptance gates;
- output artifacts;
- relevant documentation.

A skill cannot waive the automation contract.
