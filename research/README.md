# Research artifacts

This directory stores non-copyright metadata and reproducibility notes from exact local or public-source observations.

- `compiler-fingerprints/` contains hashes and sizes, never binaries.
- `tool-observations/` documents how behavior was observed and the limits of the observation.
- Public claims are summarized in `docs/RESEARCH_LEDGER.md` and linked in `docs/SOURCE_INDEX.md`.

A local observation applies only to the recorded artifact hash and date. It does not automatically qualify a compiler for accepted map generation.
